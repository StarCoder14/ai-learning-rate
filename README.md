# 수열로 본 인공지능의 학습

진로 탐구 '점화식과 등비수열의 수렴 조건을 이용한 인공지능 학습률 분석'의 코드와 자료.

인공지능의 학습(경사하강법)을 고등학교 1학년 수학만으로 분석했다. 미분 대신 이차방정식의 판별식으로 접선의 기울기를 구하고, 학습 과정을 점화식으로 바꿔 학습이 성공하는 학습률의 범위를 유도한 뒤, 시뮬레이션으로 검증했다.

| 폴더 | 내용 |
|---|---|
| `src/` | 단계별 시뮬레이션 (`stageN_이름.py`) |
| `figures/` | 그림과 애니메이션 |
| `results/` | 수치 결과 CSV |
| `docs/` | 이론 유도, 진행 상황, 보고서 초안 |
| `발표/` | 발표 슬라이드 (`발표슬라이드.html` 하나로 열림) |

## 실행

```bash
pip install numpy matplotlib
python src/stage1_quadratic.py
python src/stage7_slider.py   # 학습률 슬라이더
```
