## 2단계 — 일반 이차함수로 확장

**질문**: 함수의 모양이 달라지면 안전한 학습률도 달라지는가?

**이론**

`f(x) = a(x − p)² + q`에서 접선의 기울기는 `2a(x − p)`이므로

```
x(n+1) = x(n) − r · 2a(x(n) − p)
x(n+1) − p = (1 − 2ar)(x(n) − p)
```

`b(n) = x(n) − p`로 치환하면 **공비 (1 − 2ar)인 등비수열**. 따라서

```
|1 − 2ar| < 1   →   0 < r < 1/a
```

**예측**: a가 클수록(그래프가 뾰족할수록) 안전한 학습률의 상한이 작아진다. p와 q는 조건에 영향을 주지 않는다.

**구현** `src/stage2_general_quadratic.py`
- a ∈ {0.5, 1, 2, 5}, 각 a마다 r을 0.05 간격으로 훑어 실제 수렴 여부를 판정
- 이론 상한 `1/a`와 실제 경계가 일치하는지 표로 대조
- p, q를 바꿔도 결과가 같은지 확인 (통제변인 검증)

**해석 포인트**: 실제 AI에서 학습률을 데이터마다 다시 정해야 하는 이유가 여기서 설명된다.

**검증 결과 (완료)** — `src/stage2_general_quadratic.py`

판정은 공식 `1 − 2ar`을 쓰지 않고, 학습 규칙(기울기만큼 빼기)을 200번 반복한 뒤
꼭짓점까지의 거리가 줄었는지(수렴) / 그대로인지(진동) / 커졌는지(발산)로 했다. 이론과 독립된 근거가 되도록.

| a | 이론 상한 1/a | 실험: 수렴한 가장 큰 r | 실험: 처음 수렴 안 한 r | 이론 최적 1/(2a) | 실험: 가장 빠른 r |
|---|---|---|---|---|---|
| 0.5 | 2 | 1.95 | 2.0 (진동) | 1 | 1 (a1에서 도달) |
| 1 | 1 | 0.95 | 1.0 (진동) | 0.5 | 0.5 (a1) |
| 2 | 0.5 | 0.45 | 0.5 (진동) | 0.25 | 0.25 (a1) |
| 5 | 0.2 | 0.15 | 0.2 (진동) | 0.1 | 0.1 (a1) |

- **네 경우 모두 이론과 일치.** 경계값 1/a에서는 정확히 진동이 나타났다 (1단계의 r = 1.0과 같은 현상).
- **통제변인 검증 (a = 2)**: (p, q) = (0, 0), (3, −2), (−5, 10), 시작 거리 1 → 10 모두 판정이 완전히 같았다.
  q는 기울기 `2a(x−p)`에 아예 등장하지 않으므로 당연하고, p는 치환 `b = x − p`로 사라진다.
- **코드 검증**: a = 1일 때 r = 0.1의 20번째 항 0.0115로 1단계 결과와 같다.
- 발견: 가장 빠른 학습률 `1/(2a)`는 안전 상한 `1/a`의 정확히 절반이다. 뾰족한 함수일수록 둘 다 작아진다.

산출물: `results/2단계_판정표.csv`, `2단계_경계비교.csv`, `2단계_통제변인검증.csv`,
`figures/그림4_이차함수_수렴경계.png`(이론 상한과 실험 판정 대조), `그림5_같은학습률_다른함수.png`(r = 0.22로 a만 바꾼 경로)

## 3단계 — 2변수 함수의 지그재그

**질문**: 변수가 두 개면 왜 경로가 지그재그가 되는가?

**이론**

`f(x, y) = a·x² + b·y²`는 두 축이 서로 영향을 주지 않으므로 **등비수열 두 개가 동시에 돈다.**

```
x(n+1) = (1 − 2ar) x(n)
y(n+1) = (1 − 2br) y(n)
```

- 안전 조건: 두 조건을 모두 만족해야 하므로 `r < 1/max(a, b)` — **더 뾰족한 축이 상한을 결정**
- 수렴 속도: 더 완만한 축이 늦게 도착하므로 **덜 뾰족한 축이 전체 속도를 결정**
- 두 값의 비 `max(a,b)/min(a,b)`가 클수록 지그재그가 심하다

**구현** `src/stage3_two_variables.py`
- (a, b) = (1,1), (1,3), (1,10)에 대해 등고선 위에 경로를 그린다
- 각 경우 도달까지 걸린 항의 수를 표로 정리

**주의**: 이것을 '고유값'이나 '조건수'라고 부르지 말 것. 두 등비수열의 비교로만 서술한다.

**이론 보강 — 가장 좋은 학습률**

느린 쪽 공비의 절댓값 `max(|1−2ar|, |1−2br|)`이 가장 작아지는 것은 두 절댓값이 같을 때다.
r을 키우면 x축 공비는 작아지고 y축 공비의 절댓값은 (음수 쪽으로) 커지므로, 둘이 만나는 곳이 최적.

```
1 − 2ar = −(1 − 2br)   →   r = 1/(a + b),   그때 공비의 절댓값 = (b − a)/(b + a)
```

b/a가 클수록 이 값이 1에 가까워지므로 **가장 좋은 학습률을 골라도 느려진다.** y축 공비가 음수라 경로가 지그재그가 된다.

**검증 결과 (완료)** — `src/stage3_two_variables.py`

설정 변경: 로드맵의 (1, 3) 대신 a = 1, b ∈ {1, 2, 4, 10, 25}. 1/3은 0.005 간격 격자에 없어 경계의 진동을 확인할 수 없기 때문.
판정은 공비 공식 없이 학습 규칙을 직접 반복했고, "두 좌표 중 절댓값이 큰 쪽"으로 최솟값까지의 거리를 쟀다.

1. **안전 상한** (r을 0.005 간격으로): 다섯 경우 모두 실험 경계가 `1/max(a, b)`와 일치, 경계에서는 진동.
   → **더 뾰족한 축이 상한을 정한다.**

2. **가장 좋은 학습률과 속도**

   | b/a | 이론 최적 r | 공비 크기 | 이론 도달 항 | 이론 r로 실험 | 0.001 간격 격자에서 가장 빠른 r |
   |---|---|---|---|---|---|
   | 1 | 0.5 | 0 | 1 | 1 | 0.5 (1) |
   | 2 | 0.333 | 0.333 | 7 | 7 | 0.314~0.343 (7) |
   | 4 | 0.2 | 0.6 | 14 | 14 | 0.195~0.201 (14) |
   | 10 | 0.0909 | 0.818 | 35 | 35 | 0.090~0.091 (35) |
   | 25 | 0.0385 | 0.923 | 87 | 87 | 0.038 (88) |

   모두 일치. b = 25에서 격자 최선이 88인 것은 이론 최적 1/26이 격자에 없기 때문이며,
   1/26을 직접 넣으면 87로 이론과 같고 격자의 어떤 r도 이보다 빠르지 않았다. (처음엔 격자만 보고 "불일치"로 나왔던 부분)

3. **작은 학습률 r = 0.03** (모든 b에서 안전): 다섯 경우 모두 **112번째 항**으로 같았고, 이론(0.94를 몇 번 곱해야 0.001 미만인가)과 일치.
   y축은 b가 클수록 빨리 도달했지만(55 → 8항) 전체 속도는 항상 완만한 x축이 정했다.

**3단계 → 4단계 연결 (보고서 흐름)**
뾰족한 축 때문에 학습률을 작게 써야 한다(실험 1) → 그러면 완만한 축이 느리게 도착한다(실험 3)
→ 4단계에서 작은 학습률(r = 0.05)에 관성을 주면 66항 → 18항으로 빨라졌다. 이것이 실제 AI가 모멘텀을 쓰는 이유다.

코드 검증: b = 1, r = 0.1의 20번째 항 (0.0115, 0.0115)로 1단계와 같다.

## 4단계 — 모멘텀과 3항 점화식 (가장 추천)

**질문**: 관성을 주면 왜 더 빨리 학습하는가?

**이론**

직전 이동량을 일부 이어받는 방식(모멘텀 계수 m):

```
x(n+1) = x(n) − 2r·x(n) + m(x(n) − x(n−1))
x(n+1) = (1 + m − 2r)·x(n) − m·x(n−1)
```

**앞의 두 항으로 다음 항을 정하는 3항 점화식.** 이 수열의 거동은 특성방정식으로 결정된다.

```
t² − (1 + m − 2r)·t + m = 0
```

여기서 **판별식이 다시 등장한다.**

- `D > 0` → 두 실근 → 계단형으로 수렴
- `D < 0` → 허근 → 빙글빙글 도는 나선형 수렴
- 근과 계수의 관계에서 **두 근의 곱 = m**이므로, 허근일 때 두 근의 절댓값은 `√m`.
  따라서 `m < 1`이 필요조건이 된다.

**이 단계가 탐구의 절정인 이유**: 1단계에서 접선을 구할 때 쓴 판별식이, 마지막에 수렴 형태를 판정하는 데 다시 쓰인다.
같은 도구가 처음과 끝에 등장하면서 보고서 전체가 하나로 닫힌다.

**구현** `src/stage4_momentum.py`
- m ∈ {0, 0.3, 0.6, 0.9} × r 여러 값으로 도달 항 수 비교
- 판별식 D의 부호와 실제 경로 모양(계단/나선)이 일치하는지 검증
- m = 0일 때 1단계 결과와 같아지는지 확인 (코드 검증용)

**해석 포인트**: 실제 AI 학습에 모멘텀이 표준으로 쓰이는 이유를 고1 수학으로 설명할 수 있다.

**이론 보강 — 수렴 범위 전체** (위의 `m < 1`은 필요조건일 뿐이라 완전한 조건을 유도)

특성방정식 `g(t) = t² − (1 + m − 2r)t + m`의 두 근이 모두 −1과 1 사이에 있을 조건은
`g(1) > 0`, `g(−1) > 0`, 두 근의 곱 `m < 1`이다. (근이 1보다 큰 쪽이나 −1보다 작은 쪽에 둘 다 있으면
곱이 1보다 커지고, 한 근만 밖에 있으면 g(1)이나 g(−1)이 음수가 된다.)

```
g(1)  = 2r > 0            →  r > 0
g(−1) = 2 + 2m − 2r > 0   →  r < 1 + m
```

**결론: `0 < r < 1 + m` (단 `0 ≤ m < 1`).** m = 0이면 1단계의 `0 < r < 1`로 돌아간다.
관성을 주면 안전한 학습률의 상한이 넓어진다.

**가장 빠른 m**: 근의 절댓값 중 큰 쪽이 속도를 정한다(1단계의 |공비| 역할). 허근이면 절댓값이 `√m`이므로
허근이 되는 가장 작은 m, 즉 **중근(D = 0)** 근처가 가장 빠르다.
`(1 + m − 2r)² = 4m` → `1 + m − 2r = 2√m` → `(1 − √m)² = 2r` → `m = (1 − √(2r))²`

**검증 결과 (완료)** — `src/stage4_momentum.py`

판정은 특성방정식을 쓰지 않고, 모멘텀 학습 규칙을 2000번 직접 반복해서 했다.

1. **경로 모양** (r ∈ {0.05, 0.1, 0.2, 0.3, 0.4} × m = 0 ~ 0.95, 100가지):
   판별식으로 예측한 모양(D ≥ 0 계단형 / D < 0 출렁임)과 실제 부호가 바뀐 횟수(1회 이하 / 2회 이상)가 **100개 모두 일치.**
   (r < 0.5로 잡은 이유: 두 실근이 모두 양수가 되어 "부호가 많아야 한 번 바뀐다"는 기준이 성립)

2. **수렴 범위**

   | m | 이론 상한 1+m | 실험: 수렴한 가장 큰 r | 실험: 처음 수렴 안 한 r |
   |---|---|---|---|
   | 0 | 1 | 0.95 | 1.0 (진동) |
   | 0.3 | 1.3 | 1.25 | 1.3 (진동) |
   | 0.6 | 1.6 | 1.55 | 1.6 (진동) |
   | 0.9 | 1.9 | 1.85 | 1.9 (진동) |
   | 1 | 없음 | 없음 | 모든 r에서 진동 또는 발산 |

   **다섯 경우 모두 이론과 일치.** 경계에서는 매번 진동이 나타났다.

3. **속도** (r = 0.05, 학습률이 작은 경우)
   - 관성 없음: 66번째 항에서 도달
   - m = 0.5: **18번째 항** (약 3.7배 빠름). 이론상 큰 근의 절댓값이 가장 작은 격자값도 m = 0.5로 일치
   - 이론 최적 `m = (1 − √0.1)² ≈ 0.468`의 바로 오른쪽 격자값
   - 관성이 너무 크면 오히려 느려진다: m = 0.95는 266번째 항 (허근의 절댓값 √m이 1에 가까워짐)

**해석과 정직하게 적을 점**
- 1변수 `f(x) = x²`에서는 r = 0.5로 한 번에 도달할 수 있으므로, 관성이 속도에서 이득을 주는 것은
  **학습률을 작게 써야만 하는 상황**에서다. 왜 작게 써야만 하는지는 3단계(2변수, 뾰족한 축이 상한을 정함)가 설명한다.
  → 3단계와 4단계를 이어서 서술하면 "실제 AI가 모멘텀을 쓰는 이유"가 완성된다.
- 코드 검증: m = 0일 때 r = 0.1의 20번째 항 0.0115로 1단계와 같다.

산출물: `results/4단계_경로모양.csv`, `4단계_수렴범위.csv`, `4단계_속도.csv`,

## 4b단계 — 2변수 함수에 모멘텀 (3단계와 4단계 연결) ✅ 완료

**질문**: 3단계에서 지그재그로 느려진 `x² + 10y²`를 관성으로 빠르게 할 수 있는가?

**이론**: 축마다 4단계의 3항 점화식이 따로 돈다.
- 안전 상한: `0 < r < (1 + m)/max(a, b)`
- 최적: 두 축이 모두 허근(중근)이 되는 가장 작은 m.
  x축 `(1 − √m)² ≤ 2ar`, y축 `2br ≤ (1 + √m)²`를 함께 만족하려면
  `√m ≥ (√b − √a)/(√b + √a)`, 이때 `r = 2/(√a + √b)²`.
  b = 10이면 r ≈ 0.115, m ≈ 0.270, 속도를 정하는 수 0.818 → 0.520.

**검증 결과** — `src/stage4b_momentum_two_variables.py`
1. 안전 상한: m = 0, 0.3, 0.6, 0.9 모두 이론과 일치 (경계에서 진동).
2. 속도 (0.001 도달 기준)

   | 조건 | r | m | 속도를 정하는 수 | 도달 항 |
   |---|---|---|---|---|
   | 관성 없음 (3단계 최선) | 0.0909 | 0 | 0.818 | 35 |
   | 이론 최적 | 0.1154 | 0.270 | 0.520 | 16 |
   | 격자 탐색 최선 (m 0.01, r 0.001 간격) | 0.100~0.118 | 0.30~0.34 | 0.548~0.583 | 12 |

   **이론 최적이 격자 최선보다 느렸다 (불일치로 기록).** 원인: 이론 최적에서는 두 축이 모두 중근이라
   x(n)이 `n × 0.52ⁿ` 꼴이 되어 앞의 n 때문에 초반에 손해. 기준을 1e-5, 1e-8로 엄격하게 해도
   (24 vs 22, 35 vs 31) 뒤집히지 않았다. → 이론은 "오래 반복했을 때 줄어드는 비율"의 최적이고,
   "정해진 기준까지 걸린 항 수"의 최적과는 다르다. 관성의 효과(35 → 12~16) 자체는 확실하다.
3. 작은 학습률 r = 0.03 (3단계에서 112항): m = 0.6에서 **26항**. 이론 예측(x축 중근 m = 0.570)의 바로 옆 격자값.

## 5단계 — 로지스틱 사상과 혼돈

**질문**: 점화식의 모양을 바꾸면 수렴 말고 무엇이 나타나는가?

**이론**

```
a(n+1) = r · a(n) · (1 − a(n))
```

고정점은 `a = 0`과 `a = 1 − 1/r`. r을 키우면 수렴 → 2주기 진동 → 4주기 → 혼돈으로 전이한다.

**구현** `src/stage5_logistic.py`
- r을 0에서 4까지 훑으며 충분히 진행한 뒤의 값들을 점으로 찍어 **분기 다이어그램**을 그린다
- r = 2.5 / 3.2 / 3.5 / 3.9의 거미줄 그림 4장

**연계**: 원래 생물 개체수 모형이므로 통합과학 개체군 단원과 직접 연결된다.
"단순한 규칙에서 예측 불가능성이 생긴다"는 결론까지 갈 수 있다.

**이론 보강 (미분 없이 유도)**
- 고정점 `1 − 1/r`에서 포물선의 접선 기울기(판별식)는 `2 − r` → 고정점 근처에서 거리가 공비 `2 − r`인 등비수열처럼 움직임 → **1 < r < 3에서 수렴**
- 두 번 가면 제자리인 점: 고정점을 인수로 나누고 남는 식 `r²a² − r(r+1)a + (r+1) = 0`, **판별식 `r²(r+1)(r−3)`** → r > 3에서 주기 2 탄생
- 주기 2의 안정성: 두 점의 기울기 곱을 **근과 계수의 관계**로 계산하면 `−r² + 2r + 4` → **3 < r < 1 + √6 ≈ 3.449**
- 주기 4 → 8, 혼돈 시작(≈ 3.57)은 유도하지 않고 관찰만

**검증 결과 (완료)** — `src/stage5_logistic.py` (실행 약 25초)
1. 고정점과 공비 (r = 0.1 ~ 2.9, 28개): 27개는 고정점과 거리의 비(공비)까지 이론과 일치.
   r = 2.5는 a(0) = 0.2 → 0.4 → **0.6(고정점에 정확히 도착)**이라 공비를 측정할 수 없었다(고정점만 확인).
2. 갈라지는 지점 (r을 0.001 간격, 1만 번 반복 후 128개 값의 개수)

   | 변화 | 이론 | 실험 |
   |---|---|---|
   | 주기 1 → 2 | 3 | 3.000 (경계에서는 수렴이 매우 느려 값 2개로 셈) |
   | 주기 2 → 4 | 1 + √6 ≈ 3.4495 | 3.450 (격자에서 이론값 바로 다음) |
   | 주기 4 → 8 | 유도 안 함 | 3.545 |
   | 혼돈 시작 | 약 3.57 (알려진 값) | 3.571 |

   주기 2에서 실제로 오가는 두 값은 r = 3.1, 3.2, 3.3, 3.4 모두 이차방정식의 두 근과 소수 여섯째 자리까지 일치.
3. 초기값 민감성 (a(0)를 0.0000001만 바꿈): r = 2.8, 3.2, 3.5는 300항 뒤 차이 0.
   **r = 3.9(혼돈)는 26번째 항에서 차이가 0.1을 넘었다.**

**경사하강법과의 연결**: 같은 "점화식 + 고정점 근처의 공비" 도구가 쓰이지만, 로지스틱 사상은 학습 규칙이 아니라
생물 개체수 모형이다. 보고서에서는 후속 탐구·확장 사례로 두는 것이 정직하다.

## 6단계 — 실제 데이터로 선형회귀

**질문**: 지금까지의 이론이 진짜 데이터에도 통하는가?

**이론**

점 `(xi, yi)`들에 직선 `y = mx`를 맞출 때 오차제곱합은

```
E(m) = Σ(yi − m·xi)² = (Σxi²)m² − 2(Σxi·yi)m + Σyi²
```

**m에 대한 이차함수.** 따라서 2단계의 `a = Σxi²` 자리에 그대로 대입되어 `r < 1/Σxi²`가 예측된다.

**구현** `src/stage6_regression.py`
- 직접 수집한 데이터 사용 (예: 통합과학 교과서의 이산화탄소 농도–기온, 또는 본인이 측정한 자료)
- 데이터로부터 이론 상한을 먼저 계산한 뒤, 실제로 그 값에서 발산이 시작되는지 확인

**이 단계의 가치**: 추상적 이론이 실제 데이터에서 맞아떨어지는 것을 보여주면 보고서의 설득력이 크게 올라간다.
