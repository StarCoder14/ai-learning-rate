# 이론 유도

미분을 쓰지 않고 고1 교육과정만으로 AI의 학습률 수렴 조건을 유도한다.

---

## 0. 논리 사슬 (이 순서가 보고서의 뼈대)

```
y = x²의 최솟값을 찾는 것이 목표다
  → 최솟값에서는 접선의 기울기가 0이다
  → 그래서 기울기만큼 빼는 방식으로 이동한다
  → 그 과정이 점화식이 된다
  → 이 수열이 수렴하는 지점은 기울기가 0인 지점, 즉 최솟값이다
  → 따라서 수열의 수렴이 곧 학습의 성공이다
```

마지막에서 두 번째 고리(**교점 = 최솟값**)가 빠지면 수학 문제와 AI 문제가 따로 놀게 된다.
이 고리가 서론의 질문을 결론에서 회수하는 역할을 한다.

---

## 1. 접선의 기울기를 판별식으로 구하기

`y = x²` 위의 점 `(t, t²)`에서의 접선을 `y = m(x − t) + t²`로 놓고 연립한다.

```
x² = m(x − t) + t²
x² − mx + mt − t² = 0
```

접한다는 것은 **중근을 가진다**는 뜻이므로 판별식이 0이어야 한다.

```
D = m² − 4(mt − t²) = m² − 4mt + 4t² = (m − 2t)² = 0
∴ m = 2t
```

**x = t에서의 접선의 기울기는 2t.** 미분 없이 얻었다.

> 일반형: `y = a(x − p)² + q`의 경우 같은 방법으로 `m = 2a(t − p)`가 나온다. 2단계에서 사용.

---

## 2. 학습 규칙을 점화식으로

경사하강법은 "기울기가 가리키는 반대 방향으로 학습률 r만큼 이동"하는 규칙이다.

```
a(n+1) = a(n) − r × (a(n)에서의 기울기)
       = a(n) − r × 2a(n)
       = (1 − 2r) · a(n)
```

**공비가 (1 − 2r)인 등비수열.** 앞의 항으로 다음 항을 정하므로 형태상 점화식이다.

---

## 3. 수렴 조건

등비수열 `a(n) = a(0) · k^n`이 0으로 수렴할 조건은 `|k| < 1`이다.

```
|1 − 2r| < 1
−1 < 1 − 2r < 1
−2 < −2r < 0
0 < r < 1
```

**결론: 학습률은 0과 1 사이여야 안정적으로 학습한다.**

세 구간으로 나뉜다.

| 조건 | 공비 | 거동 |
|---|---|---|
| 0 < r < 0.5 | 0 < k < 1 | 한쪽에서 계단형으로 수렴 |
| r = 0.5 | k = 0 | 단 한 번에 정답 도달 |
| 0.5 < r < 1 | −1 < k < 0 | 좌우로 오가며 나선형 수렴 |
| r = 1 | k = −1 | 진동 (수렴도 발산도 아님) |
| r > 1 | k < −1 | 발산 |

---

## 4. 교점의 의미

거미줄 그림에서 `y = x`와 `y = (1 − 2r)x`의 교점은 원점이다.

- 교점에서는 `a(n+1) = a(n)`이므로 값이 더 이상 변하지 않는다 (고정점).
- 동시에 그 지점은 `x = 0`이고, 접선의 기울기 `2x`도 0이다.
- 즉 **더 이상 움직이지 않는 지점과 기울기가 0인 지점이 정확히 일치**한다.
  우연이 아니라 학습 규칙이 "기울기만큼 뺀다"로 만들어졌기 때문이다. 기울기가 0이면 뺄 것이 없어 멈춘다.

이 확인이 있어야 "수렴 = 정답 도달 = 학습 성공"이라고 말할 수 있다.

---

## 5. 거미줄 그림 읽는 법

**구성요소 4가지**

1. **축의 의미** — 가로축은 n이 아니라 a(n), 세로축은 a(n+1). 시간 축이 없다.
2. **보라색 직선** `y = (1−2r)x` — 학습 규칙 그 자체. r을 바꾸면 이 기울기만 바뀐다.
3. **점선** `y = x` — 계산 결과를 다시 입력으로 되돌리는 통로. 반복을 가능하게 하는 장치.
4. **초록 계단** — 수열의 경로. 세로 이동 = 다음 항 계산, 가로 이동 = 그 값을 다음 입력으로.

**핵심**: 보라색 직선의 기울기가 계단의 운명을 결정한다.
절댓값이 1보다 작으면 교점으로 빨려 들어가고, 1보다 크면 튕겨 나간다.

**예상 질문**: "왜 하필 y = x인가?"
→ 세로축의 계산 결과를 다시 가로축으로 옮기려면 두 값이 같아지는 선이 필요하기 때문.

## 6. 1단계 검증 결과 (완료)

조건: `a(0) = 1.0`, 20항까지, 수렴 판정 `|a(n)| < 0.001`

| 학습률 r | 공비 1−2r | 판정 | a(20) |
|---|---|---|---|
| 0.1 | 0.80 | 수렴 | 0.0115 |
| 0.25 | 0.50 | 수렴 (a10에서 도달) | 0.0000 |
| 0.5 | 0.00 | 수렴 (a1에서 즉시) | 0.0000 |
| 0.9 | −0.80 | 수렴 | 0.0115 |
| 1.0 | −1.00 | 진동 | 1.0000 |
| 1.2 | −1.40 | 발산 | 836.6826 |

**이론 예측 `0 < r < 1`과 완전히 일치.**

발견 두 가지:

- **r = 1.0의 진동** — 공비가 정확히 −1이라 1과 −1을 영원히 오간다. 거미줄 그림에서 완벽한 정사각형.
  부등식에 등호가 없는 이유를 그림 하나로 설명할 수 있는 좋은 소재.
- **r = 0.1과 r = 0.9의 a(20)이 동일** — 공비의 절댓값이 둘 다 0.8이기 때문. 단 도달 방식이 다르다(계단 vs 나선).
  "너무 작아도 너무 커도 느리고, 중간값이 가장 빠르다"는 결론의 근거.

## 7. 선행연구 관계

경사하강법의 수렴 조건은 이미 정립된 고전 이론이다. 이것은 약점이 아니라 **검증 기준이 있다는 강점**이다.

- 경사하강법은 1847년 코시(Cauchy)에서 출발했고, 현재 대학 최적화 교재의 표준 내용이다.
  일반 조건은 `r < 2/L` (L은 기울기가 변하는 정도를 나타내는 상수). `f(x) = x²`는 L = 2이므로 `0 < r < 1`.
  **본 탐구 결과와 일치한다.**
- 로지스틱 사상의 수렴 → 진동 → 혼돈 전이는 Robert May의 1976년 네이처 논문이 출발점. 5단계에서 참고.

**보고서에 넣을 차별점 문장**

> 본 탐구의 결과는 최적화 이론에서 이미 알려진 사실이나, 기존 연구가 미분을 이용해 증명하는 것과 달리
> 본 탐구는 접선의 판별식과 등비수열의 수렴 조건만으로 동일한 결론을 유도하고,
> 이를 시뮬레이션으로 검증하였다는 점에서 의의가 있다.

**주의**: 위 논문들은 영어 원문이다. 실제로 읽지 않았다면 참고문헌에 넣지 말 것.
