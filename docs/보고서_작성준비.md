- ⚠ **여기 쓰는 모든 주장에는 실제로 읽은 자료가 있어야 한다.** 읽은 자료가 없는 주장은 "알려져 있다"라고 쓰지 말고 빼거나, 자료를 먼저 찾아 읽는다.

### Ⅲ. 탐구 방법 및 과정 (약 1.5쪽)

**1. 탐구 방법**
- 모든 단계를 **"이론으로 예측 → 컴퓨터 시뮬레이션으로 검증 → 일치/불일치 서술"** 구조로 진행.
- 도구: Python (numpy, matplotlib). 결과는 CSV와 그림으로 저장.
- **판정 방법**: 공식을 쓰지 않고 학습 규칙을 수백~수천 번 직접 반복해, 최솟값까지의 거리가 줄었는지(수렴) / 그대로인지(진동) / 커졌는지(발산)로 판정 → 이론과 독립된 근거. 도달 기준은 거리 < 0.001.
- **변인 설정** (기존 `report.md` 표는 1단계만 있으므로 아래로 교체)

| 단계 | 조작변인 | 통제변인 | 종속변인 |
|---|---|---|---|
| 1 | 학습률 r (0.1, 0.25, 0.5, 0.9, 1.0, 1.2) | 함수 `x²`, 초기값 1.0, 20항 | 수렴 여부, 도달 항 |
| 2 | 뾰족한 정도 a (0.5, 1, 2, 5), 학습률 r (0.05 간격) | 꼭짓점 (0, 0), 시작 거리 1 | 수렴 경계, 가장 빠른 r |
| 3 | 두 축의 뾰족함의 비 b/a (1, 2, 4, 10, 25), 학습률 r | a = 1, 시작점 (1, 1) | 수렴 경계, 도달 항 |
| 4 | 관성 m, 학습률 r | 함수 `x²`, 초기값 1.0 | 경로 모양, 수렴 경계, 도달 항 |
| 4b | 관성 m, 학습률 r | 함수 `x² + 10y²`, 시작점 (1, 1) | 도달 항 |

- 통제변인 검증도 적는다: 2단계에서 꼭짓점과 시작 거리를 바꿔도 판정이 같았다.

**2. 탐구 과정**
- 1단계 → 2단계 → 3단계 → 4단계 → 4b단계 순서와, **각 단계로 넘어간 이유**를 한두 문장씩.
  (예: "1단계는 가장 단순한 함수라 실제와 거리가 있어, 함수의 모양을 바꿔 보았다" → 2단계)
- 코드가 맞는지 확인한 방법: 특수한 경우(a = 1, m = 0 등)에 앞 단계와 같은 값이 나오는지 확인.

## 4. 참고문헌 준비

**형식 (양식 그대로)**
- 단독 저자 책: `이종성 (1986). 일반화가능도이론. 서울: 세광출판사.`
- 여러 저자: `한범숙, 윤미란, 이경민 (1994). 청년심리학. 서울: 학지사.`
- 번역서: `서봉연 (역) (1983). 발달의 이론. W. C. Crane의 Theories of development. 서울: 중앙적성출판사.`
- 단체 저자: `천안대학교 교육연구소(1988). 기독교대학의 정체성. 천안: 천안대학교.`
- 인터넷 자료: `작성자 (연도, 인용한 월, 일). 페이지 제목. 웹사이트 이름. URL.`
- 위에 해당하지 않으면 APA

**자료마다 적어 둘 정보**: 저자(또는 작성자·단체), 연도, 제목, 출판사(또는 웹사이트 이름), URL, **내가 읽은 날짜**

**어떤 주장에 자료가 필요한가**
| 보고서의 주장 | 필요한 자료의 종류 |
|---|---|
| 등비수열의 수렴 조건, 판별식, 근과 계수의 관계 | 수학 교과서 (출판사, 연도) |
| 경사하강법이 AI 학습의 기본 방법이다 | 인공지능 입문서나 신뢰할 만한 해설 글 |
| 학습률이 너무 크면 학습이 실패한다 | 위와 같음 |
| 모멘텀이 실제로 쓰인다 | 위와 같음 |
| 로지스틱 사상과 혼돈 | 수학·과학 교양서나 해설 글 (쓰는 경우만) |
| 사용한 도구 | Python, matplotlib 공식 문서 (선택) |

- ⚠ **실제로 읽지 않은 자료는 넣지 않는다.** Cauchy(1847), May(1976) 같은 원문 논문은 읽지 않았다면 넣지 말 것.
- ⚠ AI(Claude 등)가 알려 준 내용은 참고문헌이 아니다. 같은 내용을 실제 자료에서 확인하고 그 자료를 적는다.
- 자료를 모아 오면 형식 맞추기는 도와줄 수 있다.

## 5. 쓸 때 지킬 규칙

**작성 순서** (목차 순서로 쓰지 않는다)
Ⅳ 탐구 결과 → Ⅲ 탐구 방법 및 과정 → Ⅱ 이론적 배경 → Ⅴ 결론 → Ⅰ 서론 손질 → 참고문헌 → 형식 맞추기

**용어**
- 미분 기호(f′, d/dx, ∇) 쓰지 않음
- 금지: 고유값, 헤세 행렬, 벡터 내적, 립시츠 상수, 조건수
- "특성방정식" → "3항 점화식에 딸린 이차방정식"으로 풀어 쓴다
- "모멘텀"은 처음에 "관성(모멘텀)"으로 소개하고 이후 "관성"으로 통일

**문체**
- "~하였다", "~이다" 체
- 결론을 과장하지 않는다 ("AI의 학습률을 밝혔다" ✕ → "가장 단순한 이차함수에서 학습률의 조건을 유도하고 확인하였다" ○)
- 숫자는 CSV 값 그대로. 반올림했으면 몇째 자리인지 맞춘다.

**형식 체크리스트 (제출 직전)**
- [ ] 제목 가운데 정렬, 15pt, 작은따옴표
- [ ] 제목과 이름 사이 두 줄 공백
- [ ] 학번·이름 오른쪽 정렬
- [ ] Ⅰ~Ⅴ와 소제목 번호가 양식과 같음 (Ⅴ는 1~5 모두)
- [ ] 그림·표 번호와 캡션, 본문에서 "그림1과 같이"처럼 언급
- [ ] 참고문헌 양식 준수, 본문에서 인용한 자료만 포함
- [ ] 한글/Word/PDF 중 하나로 저장해 첨부파일로 제출
