## 화면 읽는 법 (한 번만 말하기)

- 왼쪽: 거미줄 그림. 가로축 a(n) = 지금 값, 세로축 a(n+1) = 다음 값
- 보라색 직선 = 학습 규칙 `y = (1 − 2r)x`. r을 바꾸면 이 직선의 기울기만 바뀐다
- 점선 `y = x` = 계산한 값을 다시 입력으로 돌려보내는 통로
- 오른쪽: 항의 번호에 따른 a(n) 값
- 맨 위 제목: 지금 r, 공비, 판정(수렴/진동/발산)

## 조심할 점

- 슬라이더는 0.01 간격이다. **0.99는 수렴, 1.01은 발산이고, 정확히 1.00일 때만 진동**이 나온다.
  1.00 근처에서는 천천히 끌면서 제목 숫자가 `r = 1.00`이 되는 순간 손을 뗀다.
- 막대를 클릭하면 그 위치로 바로 이동한다. 0.4, 0.5처럼 대충 맞추면 되는 값은 클릭이 빠르다.
- 시간이 모자라면 둘째(0.9)를 빼고 0.4 → 1.00 → 1.2 → 0.5만 해도 된다.

## 플랜 B: 창이 안 열릴 때

- `발표슬라이드.html`은 Python 없이 열리므로 이 경우에도 슬라이드는 그대로 쓸 수 있다.
- 6번 슬라이드의 GIF(애니1)가 r = 0.4 → 0.9 → 1.1을 차례로 그린다. 같은 말을 하면서 GIF를 가리킨다.
- r = 1의 정사각형은 GIF에 없으므로 7번 슬라이드 표의 "r = 1.0, 진동" 줄을 가리키며 말로 설명한다.

## 이 시연에서 받을 수 있는 질문

- **"이 그림은 공식으로 그린 거 아니에요?"**
  → 맞다. 슬라이더는 보여 주기용이라 공비 `1 − 2r`을 그대로 곱한다.
  공식 없이 학습 규칙을 직접 반복한 검증은 2단계부터 했고, 그 결과가 8~11번 슬라이드다.
