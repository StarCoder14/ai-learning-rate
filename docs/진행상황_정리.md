## 0. 한눈에 보기

**주제**: 점화식과 등비수열의 수렴 조건을 이용한 인공지능 학습률 분석
**한 줄 요약**: AI의 학습은 점화식이고, 학습의 성공은 그 수열의 수렴이다.

| 단계 | 질문 | 이론으로 구한 답 | 실험 결과 |
|---|---|---|---|
| 1 | `y = x²`에서 학습률은 얼마여야 하나? | `0 < r < 1` | 일치 |
| 2 | 함수가 뾰족해지면? `a(x−p)² + q` | `0 < r < 1/a` | 4개 모두 일치 |
| 3 | 변수가 두 개면? `x² + b·y²` | 상한 `1/max(a,b)`, 최적 `r = 1/(a+b)` | 모두 일치 |
| 4 | 관성(모멘텀)을 주면? | `0 < r < 1 + m`, 판별식으로 경로 모양 판정 | 100/100 일치 |
| 4b | 2변수에 관성을 주면? | 최적 `√m = (√b−√a)/(√b+√a)` | 크게 빨라짐 확인, **최적점 1곳 불일치**(원인 밝힘) |
| 5 | 점화식에 곱하기를 더하면? `r·a(1−a)` | 수렴 1<r<3, 주기 2 탄생 r=3, 주기 4 탄생 1+√6 | 갈라지는 지점 모두 일치, 고정점 28개 중 27개 공비까지 일치(1개는 측정 불가), r=3.9에서 혼돈 |
| 7 | 발표 자료 | — | GIF 2개, 실시간 슬라이더 |

**탐구 전체의 이야기 흐름**

```
1단계  학습 = 등비수열, 수렴 조건 |공비| < 1 → 0 < r < 1
  ↓
2단계  함수가 뾰족할수록 안전한 학습률이 작아진다 (1/a)
  ↓
3단계  변수가 여러 개면 가장 뾰족한 축에 맞춰 학습률을 작게 써야 하고,
       그러면 완만한 축이 느리게 도착해 전체가 느려진다
  ↓
4단계  관성을 주면 3항 점화식이 되고, 판별식이 경로 모양과 속도를 결정한다
  ↓
4b단계 3단계에서 느려졌던 함수에 관성을 주면 35항 → 12~16항, 112항 → 26항
       → 실제 AI가 모멘텀을 쓰는 이유를 고1 수학으로 설명
  ↓ (확장)
5단계  점화식 모양을 조금만 바꾸면(로지스틱) 수렴 → 주기 2 → 주기 4 → 혼돈.
       갈라지는 지점도 판별식과 근과 계수의 관계로 구해진다. 통합과학 개체군 단원 연계
```

1단계에서 **접선의 기울기를 구할 때 쓴 판별식**이 4단계에서 **경로 모양을 판정할 때**, 5단계에서 **주기 2가 생기는 순간을 찾을 때** 다시 쓰인다.
같은 도구가 처음과 끝에 등장한다는 점이 이 탐구의 핵심 구조다.

## 1. 모든 단계에 공통인 방법

- **미분을 쓰지 않는다.** 접선의 기울기는 판별식 D = 0(중근 조건)으로 구한다.
  - `y = x²` 위의 점 `(t, t²)` → 기울기 `2t`
  - `y = a(x − p)² + q` → 기울기 `2a(t − p)`
- **학습 규칙**: 다음 값 = 지금 값 − 학습률 × 기울기. 이것이 점화식이 된다.
- **항상 "이론으로 예측 → 코드로 검증 → 일치/불일치 서술" 순서로 진행했다.**
- **실험 판정은 공식을 쓰지 않았다.** 학습 규칙을 수백~수천 번 직접 반복한 뒤
  최솟값까지의 거리가 줄었는지(수렴), 그대로인지(진동), 커졌는지(발산)로 판정했다.
  그래서 이론과 실험이 서로 독립된 근거가 된다. (단, 1단계 코드만 판정에 공비 공식을 사용했다.)
- **코드 검증**: 2·3·4·4b단계 모두 특수한 경우(a = 1, m = 0 등)에 앞 단계와 같은 값이 나오는지 확인했고, 모두 같았다. 5단계는 r = 2에서 고정점 0.5로 가는지 확인했다.
- 도달 판정 기준: 최솟값까지의 거리 < 0.001

## 2. 단계별 결과

### 1단계 — `f(x) = x²`

**이론**: `a(n+1) = a(n) − r·2a(n) = (1 − 2r)·a(n)` → 공비 (1 − 2r)인 등비수열 → `|1 − 2r| < 1` → **`0 < r < 1`**

| 학습률 r | 공비 | 판정 | 20번째 항 |
|---|---|---|---|
| 0.1 | 0.8 | 수렴 | 0.0115 |
| 0.25 | 0.5 | 수렴 (10번째 항에서 0.001 미만) | 0.0000 |
| 0.5 | 0 | 수렴 (1번째 항에서 바로 도달) | 0 |
| 0.9 | −0.8 | 수렴 | 0.0115 |
| 1.0 | −1 | 진동 | 1 |
| 1.2 | −1.4 | 발산 | 836.68 |

- r = 1.0은 1과 −1을 영원히 오간다 → 부등식에 등호가 없는 이유
- r = 0.1과 0.9의 20번째 항이 같다(공비의 절댓값이 둘 다 0.8) → 너무 작아도 너무 커도 느리다
- ⚠ 표에서 r = 0.1, 0.9는 "수렴"이지만 20항 안에 0.001 미만이 되지는 않았다. 표에 쓸 때 설명을 붙일 것.

그림: 그림1(항의 변화), 그림2(거미줄 그림), 그림3(수렴 조건)

### 2단계 — 일반 이차함수 `a(x − p)² + q`

**이론**: `b(n) = x(n) − p`로 치환하면 공비 `(1 − 2ar)` → **`0 < r < 1/a`**, 가장 빠른 r은 `1/(2a)`

| a | 이론 상한 | 실험 경계 | 가장 빠른 r (이론 / 실험) |
|---|---|---|---|
| 0.5 | 2 | 1.95까지 수렴, 2.0 진동 | 1 / 1 |
| 1 | 1 | 0.95까지 수렴, 1.0 진동 | 0.5 / 0.5 |
| 2 | 0.5 | 0.45까지 수렴, 0.5 진동 | 0.25 / 0.25 |
| 5 | 0.2 | 0.15까지 수렴, 0.2 진동 | 0.1 / 0.1 |

- 꼭짓점 (p, q)를 (3, −2), (−5, 10)으로 바꾸고 시작 거리를 1 → 10으로 바꿔도 판정이 완전히 같았다 (통제변인 검증)
- 가장 빠른 학습률은 안전 상한의 정확히 절반

그림: 그림4(a별 이론 상한과 실험 판정), 그림5(같은 r = 0.22로 a만 바꾼 경로)

### 3단계 — 2변수 `x² + b·y²`

**이론**: x, y가 각각 따로 등비수열이 된다 (공비 `1 − 2ar`, `1 − 2br`)
- 안전 상한: **`r < 1/max(a, b)`** — 더 뾰족한 축이 정한다
- 가장 좋은 학습률: 두 공비의 절댓값이 같아지는 **`r = 1/(a + b)`**, 그때 공비 크기 `(b − a)/(b + a)`

| b/a | 이론 상한 | 실험 경계 | 최적 r | 이론 도달 항 | 실험 도달 항 |
|---|---|---|---|---|---|
| 1 | 1 | 일치 (경계에서 진동) | 0.5 | 1 | 1 |
| 2 | 0.5 | 일치 | 0.333 | 7 | 7 |
| 4 | 0.25 | 일치 | 0.2 | 14 | 14 |
| 10 | 0.1 | 일치 | 0.0909 | 35 | 35 |
| 25 | 0.04 | 일치 | 0.0385 | 87 | 87 |

- **작은 학습률 r = 0.03**: b를 바꿔도 전부 112번째 항에서 도달(이론과 일치). 뾰족한 y축은 빨리 와도 완만한 x축을 기다린다.
- 뾰족한 축은 공비가 음수라 **지그재그**로 움직인다.
- b = 25에서 처음엔 "불일치"로 나왔는데, 이론 최적 1/26이 0.001 간격 격자에 없었기 때문이었다. 1/26을 직접 넣으면 87항으로 이론과 같았고, 판정 방법을 고쳤다.

그림: 그림9(등고선 위의 지그재그 경로), 그림10(뾰족함의 비에 따른 도달 항)

### 4단계 — 모멘텀 (1변수)

**이론**: 직전 이동량의 m배를 이어받으면
`x(n+1) = (1 + m − 2r)·x(n) − m·x(n−1)` → 앞의 두 항으로 다음 항을 정하는 **3항 점화식**
관련 이차방정식 `t² − (1 + m − 2r)t + m = 0`

- **경로 모양**: D > 0(두 실근)이면 계단형, D < 0(허근)이면 출렁이며 수렴
- **수렴 범위**: 두 근이 모두 −1과 1 사이 ⇔ g(1) > 0, g(−1) > 0, 두 근의 곱 m < 1 → **`0 < r < 1 + m` (0 ≤ m < 1)**
- **속도**: 허근이면 근의 크기가 √m(두 근의 곱이 m) → 중근 근처 `m = (1 − √(2r))²`가 가장 빠르다

| 실험 | 결과 |
|---|---|
| 경로 모양 (r 5개 × m 20개) | 판별식 예측과 **100개 모두 일치** |
| 수렴 범위 (m = 0, 0.3, 0.6, 0.9) | 경계가 1, 1.3, 1.6, 1.9로 **모두 일치**, 경계에서 진동 |
| m = 1 | 어떤 학습률로도 수렴하지 않음 (이론과 일치) |
| 속도 (r = 0.05) | 관성 없음 66항 → m = 0.5에서 18항. 이론 최적 m ≈ 0.468 |
| 관성이 너무 크면 | m = 0.95에서 266항으로 오히려 느려짐 |

그림: 그림6(m별 경로 모양), 그림7(m별 수렴 범위), 그림8(m에 따른 속도)

### 4b단계 — 2변수 + 모멘텀 `x² + 10y²`

**이론**: 두 축이 모두 허근(또는 중근)이 되는 가장 작은 m이 최적
x축 `(1 − √m)² ≤ 2ar`, y축 `2br ≤ (1 + √m)²` → **`√m ≥ (√b − √a)/(√b + √a)`**, 이때 `r = 2/(√a + √b)²`

| 조건 | r | m | 속도를 정하는 수 | 도달 항 |
|---|---|---|---|---|
| 관성 없음 (3단계 최선) | 0.091 | 0 | 0.818 | 35 |
| 이론 최적 | 0.115 | 0.270 | 0.520 | 16 |
| 격자 탐색 최선 | 0.100~0.118 | 0.30~0.34 | 0.548~0.583 | 12 |

- 안전 상한 `(1 + m)/max(a, b)`: m 4개 모두 일치
- 작은 학습률 r = 0.03: 112항 → m = 0.6에서 **26항** (이론 예측 m = 0.570 바로 옆)
- **⚠ 불일치 1곳 — 이론 최적(16항)이 격자 최선(12항)보다 느렸다.**
  - 원인: 이론 최적에서는 두 축이 모두 중근이라 값이 `n × 0.52ⁿ` 꼴이 되고, 앞에 곱해진 n 때문에 초반에 손해를 본다.
  - 기준을 0.00001, 0.00000001로 엄격하게 해도 뒤집히지 않았다 (24 vs 22, 35 vs 31).
  - 해석: 이론이 구한 것은 **"오래 반복했을 때 매번 줄어드는 비율"의 최적**이고,
    **"0.001까지 몇 번 만에 가나"의 최적**과는 다르다. 관성이 학습을 크게 빠르게 한다는 결론은 그대로다.

그림: 그림11(관성 없음 vs 있음 경로), 그림12(작은 학습률에서 m에 따른 속도)

### 5단계 — 로지스틱 사상 `a(n+1) = r·a(n)(1 − a(n))` (확장)

원래 생물 개체수 모형이다(개체가 많아지면 먹이가 부족해 다음 세대가 준다). 학습 규칙은 아니지만 같은 도구로 분석된다.

**이론** (미분 없이)
- 고정점: `a = 0` 또는 `a = 1 − 1/r`
- 고정점 근처: 포물선의 접선 기울기(판별식) `2 − r`가 공비 역할 → **1 < r < 3이면 수렴**
- 주기 2 탄생: 두 번 가면 제자리인 점의 식에서 고정점을 나누고 남는 `r²a² − r(r+1)a + (r+1) = 0`의 **판별식 `r²(r+1)(r−3)`** → **r > 3**
- 주기 2의 안정성: 두 점의 기울기 곱을 **근과 계수의 관계**로 → `−r² + 2r + 4` → **3 < r < 1 + √6 ≈ 3.449**

| 확인 내용 | 이론 | 실험 |
|---|---|---|
| 고정점과 다가가는 공비 (r = 0.1 ~ 2.9, 28개) | 고정점 `1 − 1/r`, 공비 `2 − r` | 27개 일치. r = 2.5는 a(2)가 고정점 0.6에 **정확히** 떨어져 공비를 잴 수 없었음 |
| 주기 1 → 2 | r = 3 | 3.000 |
| 주기 2 → 4 | 1 + √6 ≈ 3.4495 | 3.450 |
| 주기 4 → 8 | 유도 안 함 | 3.545 |
| 혼돈 시작 | 약 3.57 (알려진 값) | 3.571 |
| 주기 2의 두 값 (r = 3.1 ~ 3.4) | 이차방정식의 두 근 | 소수 여섯째 자리까지 일치 |
| 초기값을 0.0000001 바꾸면 | — | r = 2.8, 3.2, 3.5는 차이 0으로 줄어듦. **r = 3.9는 26번째 항에서 차이 0.1 초과** |

- r = 3.000 정확히에서는 수렴이 매우 느려 1만 번 반복 뒤에도 값 2개로 셌다(경계라서 생기는 현상).
- 보고서에서는 **후속 탐구나 확장**으로 두는 것이 정직하다. 경사하강법 자체가 혼돈을 보인다는 뜻은 아니다.

그림: 그림13(거미줄 그림 4장), 그림14(분기 다이어그램 + 이론선), 그림15(초기값 민감성)

## 4. 보고서 작성 때 주의할 점

**정직하게 적을 한계**
- `x²`, `x² + b·y²`처럼 **가장 단순한 이차함수만** 다뤘다. 실제 신경망의 손실함수는 훨씬 복잡하므로 그대로 일반화할 수 없다.
- 1변수 `x²`에서는 r = 0.5로 한 번에 도달하므로, 관성의 이득은 **학습률을 작게 써야만 하는 상황**(3단계)에서 나타난다.
- 4b단계의 이론 최적점 불일치(위 설명).
- 실험은 학습률을 0.05, 0.005, 0.001 간격 격자로 훑었으므로 격자 사이 값은 직접 확인하지 않았다.

**용어 주의**
- 금지: 미분 기호, 고유값, 헤세 행렬, 립시츠 상수, 조건수
- "특성방정식"은 고1 교과서에 없다 → "3항 점화식에 딸린 이차방정식" 정도로 풀어서 설명할 준비
- 허근, 판별식, 근과 계수의 관계, 제곱근은 고1 범위 안

**참고문헌**: 실제로 읽은 자료만 넣는다. 경사하강법(Cauchy, 1847)과 로지스틱 사상(May, 1976)은 원문을 읽지 않았다면 넣지 말 것.

**직접 설명할 수 있어야 하는 코드**
- 각 파일의 `learn` 함수 (학습 규칙을 반복하는 부분)
- `judge` 함수 (수렴·진동·발산 판정 기준)

## 5. 발표 예상 질문

| 질문 | 답의 방향 |
|---|---|
| 이론 결과를 코드에 넣은 것 아닌가요? | 2단계부터는 공식 없이 "기울기만큼 빼기"를 직접 반복해서 판정했다 |
| 왜 경계에 등호가 없나요? | 경계값에서는 매번 진동했다 (1단계 r = 1, 2단계 r = 1/a, 4단계 r = 1 + m) |
| 왜 하필 y = x를 그렸나요? (거미줄 그림) | 세로축의 계산 결과를 다시 가로축 입력으로 옮기는 통로 |
| 이미 알려진 결과 아닌가요? | 맞다. 미분 대신 판별식과 등비수열만으로 같은 결론을 유도하고 시뮬레이션으로 검증했다는 점이 차별점 |
| 이론 최적이 실험 최선과 왜 다르죠? (4b) | 이론은 "장기적으로 줄어드는 비율"의 최적. 중근이면 n이 곱해져 초반에 느리다 |
| 로지스틱은 AI랑 무슨 관계죠? | 학습 규칙은 아니다. 점화식의 모양을 조금 바꾸면 수렴 말고 주기·혼돈도 생긴다는 확장이고, 같은 판별식 도구로 갈라지는 지점을 구했다 |
| 실제 AI에도 적용되나요? | 원리를 이해하는 최소 모형이다. 뾰족한 방향 때문에 학습률을 작게 쓰고 모멘텀으로 보완하는 구조는 실제와 같다 |

**남은 탐구**
- 6단계 실제 데이터 선형회귀 — **사용할 데이터를 정해야 함.** 설득력이 가장 크게 올라간다.
  x와 y가 짝지어진 값 10~30쌍이면 된다 (예: 교과서 표, 공공데이터, 직접 측정한 자료).
  이론: 오차제곱합이 기울기 m에 대한 이차함수 `(Σx²)m² − 2(Σxy)m + Σy²`가 되므로 2단계 결과 그대로 `r < 1/Σx²`를 예측하고 검증한다.

**남은 작은 문제**
- 1단계 코드(`stage1_quadratic.py`)는 결과 파일을 실행한 폴더에 저장한다. 다시 실행하면 `figures/`, `results/`가 아닌 곳에 파일이 생긴다.
  "이전 단계 파일은 수정하지 않는다"는 규칙 때문에 그대로 두었다. 고쳐도 결과 값은 바뀌지 않는다.
