# 코드 설명 연습

> 발표 질문에서 "코드를 설명해 보세요"가 나왔을 때 쓸 정리.
> 모든 단계의 코드는 같은 두 함수로 돌아간다. **`learn`은 학습시키는 함수, `judge`는 채점하는 함수.**

## 한 줄 비유

- `learn` = 공을 비탈에 놓고 한 걸음씩 굴려 보면서, 매 걸음 공이 있던 자리를 공책에 적는 것
- `judge` = 다 굴린 뒤 공책의 마지막 줄을 보고 "골짜기에 들어갔나 / 제자리에서 왔다 갔다 하나 / 밖으로 튕겨 나갔나"를 고르는 것
- `xs`(또는 `points`) 리스트 = 그 공책. `xs[-1]`은 공책의 마지막 줄 = 지금 위치

---

## 1단계 `src/stage1_quadratic.py`

```python
def make_sequence(r, a0=A0, n=N_TERMS):
    ratio = 1 - 2 * r
    seq = [a0]
    for _ in range(n):
        seq.append(seq[-1] * ratio)
    return seq
```

- `ratio = 1 - 2 * r`: 공비. 이론에서 구한 값을 그대로 씀
- `seq = [a0]`: 공책 첫 줄에 시작값 1.0을 적음
- `for _ in range(n):` 20번 반복. `_`는 "몇 번째인지는 안 쓴다"는 뜻
- `seq.append(seq[-1] * ratio)`: 마지막 줄에 공비를 곱해서 다음 줄에 적음 = 등비수열

`judge`는 `|공비| < 1`이면 수렴, `= 1`이면 진동, `> 1`이면 발산이라고 판정한다.

> **정직하게 말할 것**: 1단계만 판정에 공비 공식을 썼다. 그래서 2단계부터는 공식 없이 판정하도록 바꿨다.

## 2단계 `src/stage2_general_quadratic.py` (가장 중요한 코드)

```python
def slope(x, a, p):
    return 2 * a * (x - p)

def learn(a, r, p=P, d0=D0, n=N_TERMS):
    xs = [p + d0]
    for _ in range(n):
        x = xs[-1]
        xs.append(x - r * slope(x, a, p))   # 기울기의 반대 방향으로 r만큼 이동
        if abs(xs[-1] - p) > d0 * 1e6:      # 너무 커지면 발산으로 보고 중단
            break
    return xs
```

- `slope`: 판별식으로 구한 접선의 기울기 `2a(x − p)`를 그대로 옮긴 것
- `x - r * slope(...)`: **슬라이드 3의 학습 규칙 "다음 값 = 지금 값 − r × 기울기" 그 자체**
- 여기에는 공비 `1 − 2ar`이 어디에도 없다. 기울기만큼 빼는 걸 200번 반복할 뿐
- `> d0 * 1e6`: 처음 거리의 100만 배를 넘으면 더 볼 필요 없이 멈춤 (컴퓨터가 너무 큰 수를 다루다 터지지 않게)

```python
def judge(xs, p=P):
    d_first = abs(xs[0] - p)
    d_last = abs(xs[-1] - p)
    if math.isclose(d_last, d_first, rel_tol=1e-6):
        return "진동"
    return "수렴" if d_last < d_first else "발산"
```

- 처음 거리(`d_first`)와 마지막 거리(`d_last`)만 비교한다
- 거의 같으면 진동, 줄었으면 수렴, 늘었으면 발산
- `math.isclose`를 쓴 이유: 컴퓨터 계산은 소수점 끝자리가 조금씩 틀어져서 `==`로 비교하면 진동을 놓칠 수 있음

## 3단계 `src/stage3_two_variables.py`

```python
x = x - r * (2 * a * x)              # x방향 기울기만큼 뺀다
y = y - r * (2 * b * y)              # y방향 기울기만큼 뺀다
```

- 2단계 규칙을 x와 y에 **각각 따로** 적용한 것. 공 두 개를 동시에 굴리는 셈
- `size_of(point)` = `max(|x|, |y|)`: 두 공 중 **더 늦게 오는 공**의 거리. 그래서 완만한 축이 속도를 정한다는 결과가 나온다

## 4단계 `src/stage4_momentum.py`

```python
move = x - prev                             # 직전에 움직인 양
xs.append(x - r * slope(x) + m * move)      # 기울기만큼 빼고, 관성만큼 더 간다
prev = x
```

- `prev` = 한 칸 전 위치. 공책에서 마지막 줄 바로 윗줄
- `move` = 직전에 움직인 양. 내리막을 달려온 기세
- `+ m * move`: 그 기세의 m배만큼 더 간다 = 관성. m = 0이면 2단계 규칙과 똑같음
- 앞의 두 항(`x`, `prev`)으로 다음 항을 정하니까 **3항 점화식**

```python
def judge(xs):
    size = max(abs(x) for x in xs[-20:])
    if size < 1e-6:
        return "수렴"
    return "발산" if size > 100 else "진동"
```

- 마지막 20개 항 중 가장 큰 크기를 본다. 관성이 있으면 출렁이니까 마지막 한 개만 보면 우연히 작을 수 있음
- 아주 작으면 수렴, 아주 크면 발산, 그 사이면 진동

```python
def sign_changes(xs):
    alive = [x for x in xs if abs(x) > 1e-200]
    return sum(1 for a, b in zip(alive, alive[1:]) if a * b < 0)
```

- 경로 모양(계단형/출렁임)을 판정하는 함수. 이웃한 두 항을 곱해서 음수면 부호가 바뀐 것
- 1번 이하면 계단형, 2번 이상이면 출렁임. 이걸 판별식 예측과 비교해 100/100 일치가 나왔다

> 코드 주석에 "특성방정식"이라는 말이 있다. 질문에서는 **"3항 점화식에 딸린 이차방정식"** 이라고 말한다.
