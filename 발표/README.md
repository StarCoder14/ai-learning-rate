# 발표 슬라이드

**발표할 때 여는 파일: `발표슬라이드.html`** (더블클릭하면 브라우저로 열림)

그림과 GIF가 파일 안에 다 들어 있어서 이 파일 하나만 USB에 담아 가도 됨. 인터넷이 없으면 글꼴만 맑은 고딕으로 바뀜.

## 조작

| 키 | 하는 일 |
|---|---|
| → 또는 스페이스, 클릭 | 다음 슬라이드 |
| ← | 이전 슬라이드 |
| F | 전체화면 켜기/끄기 |
| N | 화면 아래에 대본(노트) 보이기/숨기기. 청중에게도 보이니 연습할 때만 |
| P | 발표자 창 열기: 대본, 다음 슬라이드 제목, 경과 시간. 노트북 화면에 두고 발표 화면은 프로젝터로 |
| H | 조작법 안내 다시 보기 |
| Home / End | 처음 / 마지막 |

주소 끝에 `#7`을 붙이면 7번 슬라이드부터 열림. 질문 시간에 특정 장으로 돌아갈 때 씀.

## 파일

- `발표슬라이드.html`: 완성본. 아래 파일들로 만든 결과물
- `slides/<이름>.html`: 슬라이드 한 장씩. 마지막 `<aside>`가 대본
- `deck.json`: 슬라이드 순서와 제목
- `template.html`: 넘기기, 노트, 발표자 창 기능이 들어 있는 틀
- `build_slides.py`: 위 파일들을 하나로 묶는 스크립트

## 고칠 때

`slides/` 안의 파일이나 `template.html`을 고친 뒤 다시 묶으면 됨.

```bash
python 발표/build_slides.py
```
