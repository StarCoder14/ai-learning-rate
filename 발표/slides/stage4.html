관성(모멘텀)을 더하면? 판별식이 다시 등장

앞의 두 항으로 다음 항을 정하는 3항 점화식

x(n+1) = (1+m−2r)x(n) − m·x(n−1)

이 점화식에 딸린 이차방정식

t² − (1+m−2r)t + m = 0

D ≥ 0 계단형 · D < 0 출렁임: 100가지 중 100가지 일치

안전 범위 0 < r < 1 + m

그래서 실제 AI가 쓰는 방법인 관성, 모멘텀을 더해 봤습니다. 직전에 움직인 양의 m배를 이어받으면, 앞의 두 항으로 다음 항을 정하는 3항 점화식이 됩니다. 이 점화식에 딸린 이차방정식이 있는데, 여기서 처음에 접선을 구할 때 쓴 판별식이 다시 나옵니다. D가 0 이상이면 계단처럼, 0보다 작으면 출렁이며 수렴합니다. 100가지 조합으로 확인했는데 100가지 모두 맞았습니다. 안전한 범위도 0 < r < 1 + m으로 넓어졌습니다. (50초)
